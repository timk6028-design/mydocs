## Что такое GitHub?
GitHub — это крупнейшая в мире платформа для хранения кода и совместной работы над проектами. 
* **Для программистов:** это облачное хранилище для кода, где сохраняется история всех изменений (вы всегда можете откатиться назад).
* **Для команд:** это инструмент, который позволяет нескольким людям одновременно работать над одним проектом, не мешая друг другу.
* **Для всех:** это портфолио. Здесь можно показывать свои проекты работодателям или делиться ими с миром.

## Основные понятия
Чтобы не запутаться, запомните базовые термины:
* **Репозиторий (Repository / Repo)** — это папка с вашим проектом. В ней хранятся файлы кода, картинки и история изменений.
* **Коммит (Commit)** — это "сохранение". Вы вносите изменения в файл и делаете коммит, оставляя комментарий (например, "Исправил опечатку").
* **Ветка (Branch)** — это копия проекта, в которой можно безопасно экспериментировать, не ломая основной код.
* **README.md** — главный файл любого репозитория. Это "лицо" вашего проекта, где пишется инструкция и описание.

## Начало работы: Создание аккаунта
1. Перейдите на официальный сайт [github.com](https://github.com).
2. Нажмите кнопку **Sign up** в правом верхнем углу.
3. Введите свою электронную почту, придумайте надежный пароль и уникальный никнейм (Username).
4. Подтвердите аккаунт через письмо, которое придет на вашу почту.

## Создание первого репозитория
1. Войдите в аккаунт. На главной странице нажмите зеленую кнопку **New** (или значок **+** в правом верхнем углу -> **New repository**).
2. В поле **Repository name** введите название проекта (например, `my-first-project`).
3. В поле **Description** добавьте краткое описание (необязательно).
4. Выберите тип: **Public** (видно всем) или **Private** (видно только вам).
5. Поставьте галочку (или переключатель в On) напротив **Add a README file**.
6. Нажмите **Create repository**.

## Как работать с файлами
**Через браузер (самый простой способ):**
1. Зайдите в свой репозиторий.
2. Нажмите кнопку **Add file** -> **Create new file** (создать файл) или **Upload files** (загрузить файлы с компьютера).
3. Чтобы отредактировать существующий файл, откройте его и нажмите на иконку карандаша (✏️).
4. После внесения изменений прокрутите страницу вниз, напишите комментарий к коммиту (например, "Добавил инструкцию") и нажмите зеленую кнопку **Commit changes**.

## Скачивание кода
Если вы хотите работать с проектом на своем компьютере, вам понадобится **Git** (консольная программа) или **GitHub Desktop** (удобное приложение с кнопками).

**Способ 1: Скачать архивом (без установки программ)**
1. В вашем репозитории нажмите зеленую кнопку **<> Code**.
2. Выберите **Download ZIP**. Проект скачается на компьютер.

**Способ 2: Через командную строку (Git)**
1. Установите Git с официального сайта [git-scm.com](https://git-scm.com).
2. Откройте терминал (командную строку).
3. Введите команду: `git clone https://github.com/ваш-никнейм/название-репозитория.git`

**Способ 3: GitHub Desktop**
Скачайте приложение [GitHub Desktop](https://desktop.github.com/), войдите в свой аккаунт, и вы сможете делать коммиты и скачивать проекты в один клик мышкой.

## Совместная работа
* **Issues (Задачи):** Это встроенный трекер задач. Если вы нашли баг или хотите предложить идею, создайте Issue (вкладка Issues -> New Issue).
* **Pull Requests (PR):** Если вы хотите предложить изменения в чужой проект или объединить свою ветку с основной, создается Pull Request. Это запрос на то, чтобы ваши изменения проверили и добавили в проект.

## Полезные советы
* 💡 **Изучите Markdown:** Это простой язык разметки, который используется в README. Он позволяет делать заголовки (`#`), списки (`-`), жирный шрифт (`**текст**`) и ссылки.
* 💡 **Ищите готовые решения:** На GitHub миллионы проектов. Если вы ищете код на Python или библиотеку для JavaScript, просто введите запрос в поиске.
* 💡 **GitHub Pages:** Вы можете бесплатно разместить свой сайт (визитку или документацию) прямо из репозитория. Для этого зайдите в Settings -> Pages.
